# ExamMaster
A website that allows students to access school work and external education resources.This website has multiple features listed below that help the students,features such as a calculator and a periodic table for maths and science students.

AI-Powered Study Assistant
-Students paste in homework problems or essay prompts and get step-by-step guidance (not just answers)
-Explains why each step works to build understanding
-Tracks which topics a student struggles with over time and adjusts difficulty

Smart Note Summarizer
-Students upload messy class notes or textbook pages (text, photo, or PDF)
-App generates clean summaries, key terms, and flashcards automatically
-Highlights gaps in understanding with follow-up questions

Personalized Study Planner
-Student enters upcoming tests/assignments with due dates
-App breaks work into daily chunks based on difficulty and available time
-Sends reminders and adjusts the plan if they fall behind

"Explain It Differently" Tool
-When a student doesn't understand a concept after the first explanation, they tap a button
-Gets 3 different explanations: simple analogy, visual description, real-world example
-Targets the "I read it but still don't get it" problem

Homework Accountability Partner
-Students set a study goal and check in with the app
-Light gamification: streaks, badges, weekly progress reports
-Optional: share progress with a parent or tutor

Peer Study Matcher
-Students log subjects they're struggling with and ones they're confident in
-App matches them with classmates for peer tutoring sessions
